# MCD - UDG
## Programación I

Bienvenido al repositorio de la asignatura *Programación I, correspondiente a la *Maestría en Ciencia de Datos. Este espacio reúne los materiales, ejercicios y proyectos orientados al aprendizaje del lenguaje Python y al desarrollo de soluciones computacionales aplicadas al análisis de datos.

Durante el curso se abordarán los fundamentos de programación, el manejo de variables y estructuras de control, la manipulación de cadenas y archivos, las estructuras de datos, la programación orientada a objetos, las expresiones regulares, los servicios web y la integración con bases de datos SQL.

Asimismo, se utilizarán herramientas para la depuración y prueba de programas, así como Git y GitHub para el control de versiones y el desarrollo colaborativo.

# Desafíos de Programación en Python

Repositorio con mis soluciones a los 9 desafíos del documento *Desafíos_Programación_1*. Cada desafío se resolvió en un archivo `.py` escrito en VS Code, siguiendo un proceso de aprendizaje paso a paso.

## Objetivo

Reforzar y ampliar el conocimiento de Python poniendo en práctica la teoría en problemas concretos: entender el problema, diseñar una solución, codificarla, depurarla, optimizarla y documentarla.

## Metodología

1. **Estudio del desafío**: entender qué se pide antes de escribir código.
2. **Diseño de la solución**: dividir el problema en subproblemas más pequeños.
3. **Codificación**: obtener primero una solución funcional.
4. **Depuración**: probar con varios casos de prueba.
5. **Optimización**: mejorar eficiencia y legibilidad.
6. **Documentación**: comentarios que expliquen la lógica y las decisiones de diseño.
7. **Subida a GitHub**: commit con un mensaje descriptivo.

## Cómo ejecutar

Requiere Python 3 instalado. Desde la carpeta del repositorio:

```bash
python desafio_1.py
```

Cambia el nombre del archivo por el del desafío que quieras ejecutar. En VS Code también puedes usar el botón **Run Python File**.

## Criterios de evaluación

- **Funcionalidad**: resuelve el desafío como se especifica.
- **Eficiencia**: solución funcional y eficiente.
- **Legibilidad**: código claro y fácil de entender.
- **Documentación**: comentarios claros y README descriptivo.
- **Uso de conceptos de Python**: estructuras de datos, funciones, manejo de archivos, etc.
- **Robustez**: manejo de errores y entradas inesperadas.

## Conceptos practicados

Cadenas, listas, tuplas y diccionarios, funciones y funciones de orden superior, composición de funciones, lectura y escritura de archivos, manejo de excepciones y depuración.
